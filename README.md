# LinkedIn-помощник

Локальный прототип для DevOps-инженера: уточняет рабочую заметку, предлагает два варианта поста и комментарии к выбранному вами посту. Текст редактируется перед отправкой. Публикация поста требует отдельного нажатия и подтверждения. Комментарии копируются для ручной отправки. Перед каждым запросом можно выбрать генерацию через подписку Codex или OpenAI API.

## Запуск

Нужен Node.js 20+.

```bash
codex login
npm start
```

Откройте http://127.0.0.1:3000. По умолчанию используется локальный `codex exec` с вашим входом через ChatGPT, без API-ключа и без отдельной оплаты API. Он расходует лимиты вашей подписки Codex. Приложение запускает его в отдельной временной папке, с режимом только для чтения, без пользовательских настроек и без сохранения истории запуска. Если понадобится режим API, скопируйте `.env.example` в `.env`, заполните `OPENAI_API_KEY` и `OPENAI_MODEL` и выберите **OpenAI API** в интерфейсе. [Официальная документация Codex](https://learn.chatgpt.com/docs/non-interactive-mode) описывает этот способ запуска.

Заметки и черновики не сохраняются на диск приложением; выбранный режим отправляет текст в OpenAI при генерации. Не вводите сведения, которые нельзя передавать внешнему сервису.

## Как подключить LinkedIn

Локальный запуск не требует публичного сервера: callback приходит в приложение на Mac. Публичным должен быть URL политики конфиденциальности. Для этого проекта используйте [политику в GitHub](https://github.com/chernuha-dev/linkedin-ai-helper/blob/main/PRIVACY.md).

1. Создайте приложение в [LinkedIn Developer Portal](https://www.linkedin.com/developers/apps) от своего аккаунта. Для личного приложения выберите стандартную [Default Company Page for Individual Developer](https://www.linkedin.com/company/default-company-page-for-individual-developer) по её URL; отдельную компанию создавать не требуется. Укажите URL политики выше и загрузите [логотип проекта](assets/app-logo.png). Для этого проекта уже создано приложение `ai-helper`.
2. На вкладке **Products** добавьте **Sign In with LinkedIn using OpenID Connect** и **Share on LinkedIn**. Второй продукт даёт право `w_member_social` для публикации от вашего имени.
3. На вкладке **Auth** укажите точный Redirect URL: `http://127.0.0.1:3000/auth/callback`. LinkedIn принял этот URL для `ai-helper`. Если используете другой `PORT`, измените URL соответственно. Важны те же хост, порт и путь; `localhost` и `127.0.0.1` — разные строки для проверки URL.
4. Скопируйте `.env.example` в `.env`, затем внесите **Client ID** и **Client Secret** как `LINKEDIN_CLIENT_ID` и `LINKEDIN_CLIENT_SECRET`. Перезапустите сервер.
5. Нажмите **Подключить** в приложении и подтвердите доступ на странице LinkedIn. Пароль и cookies приложению не передаются.

Приложение запрашивает `openid profile w_member_social`. Токен хранится только в оперативной памяти сервера и исчезает при перезапуске или нажатии **Отключить**. Оно слушает только `127.0.0.1` и рассчитано на личное локальное использование.

## Границы текущей версии

- Посты создаются через официальный LinkedIn API после вашего подтверждения. OAuth-подключение проверено; фактическая публикация ещё не проверялась, чтобы не размещать тестовый пост без вашего одобрения.
- Поиск чужих постов по теме и отправка комментариев из приложения не включены: обычный самостоятельный доступ к поиску ленты LinkedIn не предоставлен. Вставьте текст найденного вами поста, получите варианты и отправьте выбранный комментарий вручную.
- Если для выбранного режима нет входа в Codex CLI или API-ключа, интерфейс показывает недостающую настройку. Перед публикацией всегда проверяйте факты и конфиденциальность.
